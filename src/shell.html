Load this area reads buildings from the vector tiles, whose outlines sit on a ~37 cm grid. Addresses are not in those tiles at all — for addresses, or for exact geometry, use Get this area's data: it opens the server's own export in a new tab, which the browser allows where a direct fetch is refused. Copy that text into the box above, or save it and open the file. A response of just <osm version="0.6"/> means nothing is pending there, so pan elsewhere.
